# caatinga-malware-db

**English** | [Português (Brasil)](./README.pt-BR.md)

Official repository of the **Caatinga Malware DB (CMDB)** project, maintained by the [UFPE-Segurança-Ofensiva](https://github.com/UFPE-Seguranca-Ofensiva) organization. This project aims to provide an **academic malware database** for **study, analysis, and research in offensive security**.

**Caatinga Malware DB** is focused on educational use and is fed by students from the Lato Sensu Graduate Program in Offensive Security and Cyber Intelligence at UFPE, along with the cybersecurity community.

## Purpose

- Provide a reliable collection of malware samples for static and dynamic analysis.
- Support lab activities within the graduate program courses.
- Encourage academic and technical contributions to sample curation.
- Promote the safe, ethical, and controlled study of real-world malware in isolated environments.

## Disclaimer

⚠️ **WARNING:** This repository contains **references, metadata, and real malware samples**. The samples must be handled with extreme care, only in **sandboxed/isolated environments**, and **never on production systems**.

All project ZIP files must remain encrypted with the conventional password `infected`. This password reduces accidental opening risk but does not replace isolation or access control.

This content is intended **strictly for educational and research purposes**. Any malicious use is strictly prohibited. The maintainers of this project **do not take responsibility for misuse** of the materials.

Read the complete [Disclaimer and Responsible Use Notice](./DISCLAIMER.md) before downloading or handling any material.
